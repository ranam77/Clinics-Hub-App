## 🚧 Under Construction

ClinicsHub is an Android application project designed to showcase clinic-related software solutions and projects.

The application is currently under development.

## Current Features

- Projects listing screen.
- Fragment-based architecture.
- Navigation Component.
- Bottom navigation (Home, Login, About).
- REST API integration (planned).

## Technologies

- Java
- Android SDK
- AndroidX
- Navigation Component
- RecyclerView
- Material Design
